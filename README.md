# Waveform.exe
El Waveform Manager / Designer (OTO) sirve para crear, editar, organizar y reutilizar waveforms (señales tipo 0/1 o analógicas discretizadas) que se usan como perfiles de simulación/prueba en electrónica automotriz (por ejemplo, para emular señales de CKP/CMP, switches o entradas A/D) y así validar módulos/ECUs/PCMs sin depender del vehículo.
